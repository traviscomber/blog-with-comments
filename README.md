# Blog with Comments — Historical Learning Project

This repository is a **historical implementation exercise derived from the Next.js/Vercel blog example**, extended with authenticated comments using Auth0 and Upstash.

It is preserved as part of the GitHub learning/experimentation record. It is **not a N3uralia product** and is not presented as original product authorship in the portfolio.

Original example lineage: [Next.js examples](https://github.com/vercel/next.js/tree/canary/examples/blog)

---

## What this project explored

- extending an existing Next.js example;
- authenticated user comments;
- user-owned comment deletion;
- administrator moderation;
- serverless Redis persistence with Upstash;
- Auth0 authentication;
- deployment configuration for a small full-stack web application.

The repository predates the current N3uralia operating-system architecture and remains public only as historical engineering practice.
